Theorem: Correctness of Triangle Inequality Pruning

Let $M = (X, d)$ be a discrete metric space with elements $Q, P, C \in X$ where $Q$ is the search query, $P$ is the current pivot node, and $C$ is a child node connected by an edge of weight $d(P, C)$.

By the Triangle Inequality Axiom:

1. d(Q, P) ≤ d(Q, C) + d(P, C) ⇒ d(Q, C) ≥ |d(Q, P) - d(P, C)|

2. d(Q, C) ≤ d(Q, P) + d(P, C)

Therefore: |d(Q, P) - d(P, C)| ≤ d(Q, C) ≤ d(Q, P) + d(P, C)

For any target tolerance $\tau$, the child subtree can contain a candidate $d(Q, C) \le \tau$ only if the edge weight satisfies:
d(Q, P) - τ ≤ d(P, C) ≤ d(Q, P) + τ.
Any edge outside this closed interval is mathematically guaranteed to contain zero matches and is safely pruned in $O(1)$.

Metric Space Axioms (Hamming Metric)

The 100-bit perceptual feature bitstring distance function $d_H(u, v) = \text{count\_nonzero}(u \oplus v)$ strictly satisfies all 4 metric axioms:

1. Non-negativity d(x, y) ≥ 0
2. Identity of Indiscernibles d(x, y) = 0 ⇔ x = y
3. Symmetry d(x, y) = d(y, x)
4. Triangle Inequality d(x, z) ≤ d(x, y) + d(y, z)
